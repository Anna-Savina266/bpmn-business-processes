# BPMN-моделирование бизнес-процессов
Групповой проект

## Описание
Моделирование ключевых бизнес-процессов в нотации BPMN 2.0 для системы:
- BOS (BarberShop) — процесс онлайн-записи клиента и выполнения услуги мастером

Проект выполнен в группе из 2 человек. Моя роль: Аналитик процессов — ответственность за выделение основных/обеспечивающих процессов, построение диаграмм уровня 1–2, проведение ревизии соответствия артефактов.

## Что сделано
- Выделены основные и обеспечивающие бизнес-процессы по правилам декомпозиции
- Построены детализированные BPMN-диаграммы (уровень 1 и 2):
  - Онлайн-запись клиента (BOS)
  - Выполнение услуги и сбор обратной связи (BOS)
- На диаграммах указаны: события, шлюзы, задачи, роли исполнителей, потоки данных
- Проведена ревизия: сопоставление с контекстной диаграммой, глоссарием, бизнес-требованиями

## Технологии и инструменты
`BPMN 2.0` `Business Process Modeling` `Draw.io` `Excel`

## Чему научилась
- Применять процессный подход вместо функционального (видеть сквозные цепочки между ролями)
- Строить диаграммы, понятные не только разработчикам, но и бизнесу
- Выявлять узкие места и точки интеграции с внешними системами
- Работать в команде: распределять задачи, согласовывать решения, проводить ревизию
- Документировать бизнес-логику до начала разработки — снижает количество переделок
